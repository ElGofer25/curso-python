# Fundamentos de Python

Lee los archivos del `01` al `12`. Cada uno incluye una explicación breve,
ejemplos ejecutables y un reto al final. Se usa Python 3 y no hay dependencias.

Ejecuta un tema desde esta carpeta:

```sh
python3 05_listas.py
```

1. Variables, tipos y conversiones.
2. Operadores aritméticos, comparaciones y lógica.
3. Cadenas de texto, índices y formato.
4. Entrada y salida con `input` y `print`.
5. Listas: modificación, copias y ordenamiento.
6. Tuplas: inmutabilidad y desempaquetado.
7. Diccionarios y conjuntos.
8. Condicionales `if`, `elif` y `else`.
9. Ciclos `for`, `range`, `break` y `continue`.
10. Ciclos `while` y condiciones de salida.
11. Funciones, parámetros y `return`.
12. Práctica integradora.

Antes de ejecutar un ejemplo, intenta predecir su salida. Después cambia un
dato y explica por qué cambia el resultado. Resuelve los retos en `Ejercicios/`.
